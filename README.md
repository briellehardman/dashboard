# Dashboard

This project is a personal dashboard created for WRIT 40363.

The dashboard includes sample weather data, a random quote generator, a task list, and a light and dark theme.

## Built With

- HTML
- CSS
- JavaScript
- JSON
- fetch()
- localStorage
- CSS Grid

## Features

- Sample weather loaded from a JSON file
- Random quote generator
- Quote button that avoids showing the same quote twice in a row
- Task list with add, complete, and delete options
- Task information saved with localStorage
- Light and dark theme toggle
- Theme preference saved after refreshing the page
- Responsive layout
- Loading and error states
- Accessibility improvements
